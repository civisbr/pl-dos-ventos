# Convenções do projeto

- Todos os commits humanos deste repositório usam `CivisBR <compact.chipmunk.sqpx@mask.me>` como autor e committer, conforme o padrão do civisbr/visse e do civisbr/folego. Nunca use a identidade pessoal do proprietário.
- Configure essa identidade apenas neste repositório com `git config --local`; não altere a identidade global.
- Mensagens de commit com prefixos `feat:`, `fix:`, `docs:`, `test:` e `chore:`, em inglês. Não reescreva commits publicados.
- Documentos e minutas em português (pt-BR), em registro formal e impessoal.
- Minuta é versão preliminar até revisão jurídica externa; não apresentar como proposição oficial.
